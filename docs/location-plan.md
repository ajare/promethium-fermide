# Location plan

Select a Room, Corridor, or Facade in the World canvas and choose **Location plan** in Selection. The plan opens at the clicked World Level. A single reusable window stays pinned to that Location even when ordinary Selection changes; choosing the button for another Location explicitly retargets it. The Level selector lists World Levels, including the Location's vertical offset, not Location-local supporting-Level offsets.

The grid's horizontal labels are World X, including the Location's horizontal offset. It shows integer Local depths 0–3 at minimum, with 0 at the bottom. Contents on the displayed supporting Level expand the range to retain one row beyond the greatest instance or resolved Furniture vertex depth, including catalogue offsets. The range never automatically shrinks after movement or deletion (or when changing Level). Local depth describes ordering, not physical distance, World height, or Layer. The Location's Layer is shown separately.

World content is recorded in `WorldDrawList`, clipped to the plan viewport and rendered by MPP into a dedicated offscreen texture. It never overwrites the main World canvas texture before ImGui composites both images.

Closing and reopening starts a fresh view at the selected Level. History reconstruction refreshes the view only when the same World still has a matching authored Location at its pinned index (type, name, Layer, position, and extent). World replacement, target deletion, and mismatching reconstructed Locations close the transient view rather than blindly rebinding a reused Sector index. Opening again selects the current World-owned Location. The plan adds no document data or persistence schema.

Furniture belonging to the pinned Location and displayed supporting Level appears as labelled horizontal-footprint rectangles, one row at the instance Local depth. Fractional X, negative tile offsets, and the full multi-tile artwork width are preserved; artwork height does not become physical depth. Gold dots indicate usable points at their resolved route depths (or instance depth for definitions without explicit routes). Unsupported Floor spans are shaded, including gaps in upper-Level Walkways. Shading is guidance only: existing Furniture validation remains authoritative.

While the plan is open, the World palette gains a third row of definitions from the currently attached Furniture catalogue, independent of focus/hover. Large catalogues use **Next page** to keep every definition accessible within the tray. Long labels are clipped to their slots and shown in full in hover tooltips. Without a catalogue, the row displays a diagnostic rather than stale definitions.

Drag a definition into the plan grid to place Furniture on its pinned Location and selected Level. New placements always snap to whole World-cell X and integer Local depth, even with Shift held. Green/red footprint previews use ordinary Furniture validation without changing the World. Releasing a valid candidate creates one normal, uniquely named instance (for example Chair, Chair 2) and one undoable document edit. Unsupported Floor, boundary crossings, overlap, other UI surfaces, and stale catalogue/Location/World targets cannot receive a placement. Escape/right-click cancels a drag. Save/reopen and undo/redo use ordinary Furniture persistence and retain owned Marker identities.

Click an existing footprint to select its instance in the existing **Furniture** controls without changing the pinned plan. The selected footprint has a gold outline. Left-drag previews movement with whole-cell X snapping; holding Shift allows fractional X, and changing Shift immediately updates the preview. Local depth remains a non-negative integer. Movement keeps the same Location and supporting Level. A valid release inside the grid commits exactly one undoable edit and preserves instance and owned Marker identities and names; invalid or cancelled releases change nothing. Reconstruction, deletion, or catalogue replacement invalidate stale selections and gestures. Pre-existing Furniture can be moved without palette placement.

Choose **Delete selected Furniture** to remove the selected instance on the pinned Location and displayed Level. The plan uses existing reference-safe deletion: a refused operation displays its diagnostic and preserves contents, selection, references, and history. Successful deletion clears selection and gestures and commits one undoable edit. Undo restores the instance and owned Marker identities; redo removes them again without retargeting the plan or shrinking its expanded depth range. Selection of Furniture outside the displayed plan cannot be deleted through this control.
