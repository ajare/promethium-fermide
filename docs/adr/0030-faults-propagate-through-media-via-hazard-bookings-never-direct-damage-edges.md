# Faults propagate through media via hazard bookings, never through direct damage edges

A Fault on one Station Installation must be able to affect other components (a battery runaway poisoning a compartment, a coolant puncture starving a chiller), but we decided there will be no "this fault damages that component" declarations: a Fault's only outward effect on the world beyond its own Installation is a **hazard booking** — an accounted one-shot or rate emission of mass, species, or heat into a shared medium (Thermal reservoir, Atmosphere compartment, Resource store) — and every downstream effect comes from the other components' own gates, caps, and stressors reacting to that medium. Direct damage edges were rejected because they create a second, hand-maintained coupling graph that must be kept consistent with the physical wiring, cannot express unauthored cascades, and give mass and energy nowhere to be booked. The booking rides the same ledger path as every normal flow, so the per-tick conservation audit closes on a fault's consequences or flags `healthy = false`. See `docs/specs/station_degradation_failure_specification.md`.
